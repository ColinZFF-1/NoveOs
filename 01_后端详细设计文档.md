### 1.2 核心设计原则

| 原则 | 说明 | 落地手段 |
|------|------|---------|
| **配置驱动** | 所有行为由 book.yaml + 类型插件决定，代码零硬编码 | BookConfig dataclass 全局注入 |
| **状态持久化** | 任何时刻系统崩溃，重启后可精确恢复 | SQLite WAL 模式 + 每章事务提交 |
| **失败隔离** | 单章失败不阻塞全书，单项目失败不阻塞全局 | 子进程/线程池隔离 + 超时熔断 |
| **可观测** | 每个 Agent 调用、每次状态变更都有迹可循 | 结构化日志 + Prometheus 指标 + 审计追踪 |
| **向后兼容** | API 升级不破坏旧版前端 | URL 版本控制 (/api/v1/*) |

### 3.2 值对象（Value Object）

```python
# domain/value_objects.py
from dataclasses import dataclass
from typing import Literal
from decimal import Decimal

@dataclass(frozen=True)
class WordCount:
    value: int
    MIN: int = 4050
    MAX: int = 4950

    def is_valid(self) -> bool:
        return self.MIN <= self.value <= self.MAX

    def deviation_pct(self) -> Decimal:
        target = 4500
        return Decimal(abs(self.value - target)) / target * 100

@dataclass(frozen=True)
class EmotionCoordinate:
    x: int  # 章节号
    y: int  # -100 ~ +100
    mode: Literal["紧", "压抑", "虐", "燃", "甜"]
    desc: str
    is_predicted: bool = False

@dataclass(frozen=True)
class AuditScore:
    ta_density: float        # 他字密度 %
    forbidden_count: int
    style_break_score: int   # 0-6
    sensory_count: int
    era_count: int
    shuang_count: int

    def is_blocking(self) -> bool:
        return (
            self.ta_density > 15 or
            self.forbidden_count > 3 or
            self.style_break_score < 3 or
            self.sensory_count < 3
        )
```

```sql

    genre           TEXT NOT NULL,

    project_id      TEXT NOT NULL,
    chapter         INTEGER NOT NULL,
    character_name  TEXT NOT NULL,

    emotional_state TEXT,

    state_history TEXT,  -- JSON [{chapter, state}]
    FOREIGN KEY (project_id) REFERENCES projects(project_id),
    UNIQUE(project_id, chapter, item_name)

CREATE TABLE debts (

    status          TEXT DEFAULT 'pending',
    PRIMARY KEY (project_id, fs_id),
    FOREIGN KEY (project_id) REFERENCES projects(project_id)
);

-- 配角出场调度表
CREATE TABLE cast_schedule (

CREATE TABLE emotion_history (

-- 章节历史
CREATE TABLE chapter_history (

### 4.2 事务策略

| 操作 | 隔离级别 | 事务范围 | 说明 |
|------|---------|---------|------|
| 单章写作完成更新 | SERIALIZABLE | chapter_history + character_states + debts + foreshadowing | 保证跨表一致性 |
| 快照创建 | READ COMMITTED | 单表 chapter_snapshots | 允许并发读 |
| 日志写入 | READ UNCOMMITTED | 单表 runtime_logs | 性能优先，允许丢失 1 条 |
| 项目初始化 | SERIALIZABLE | 全表批量 INSERT | 初始化期间禁止读写 |

    v

### 6.2 限流策略

```python
from fastapi import Request, HTTPException
import time

class RateLimiter:
    def __init__(self):
        self.buckets = {}

    def is_allowed(self, key: str, limit: int, window: int = 60) -> bool:
        now = time.time()
        if key not in self.buckets:
            self.buckets[key] = []
        self.buckets[key] = [t for t in self.buckets[key] if now - t < window]
        if len(self.buckets[key]) >= limit:
            return False
        self.buckets[key].append(now)
        return True

async def rate_limit(request: Request, limit: int = 100):
    key = f"{request.client.host}:{request.url.path}"
    if not limiter.is_allowed(key, limit):
        raise HTTPException(429, "Too Many Requests")

## 7. Agent 调用链时序

### 7.1 正常流程时序图

User -> BatchWriter -> StateManager -> PromptBuilder -> LiteLLM -> Director/Writer/Polish/Auditor -> QualityGates

1. User 调用 start
2. BatchWriter 向 StateManager 查询本章状态（债务、伏笔、人物快照）
3. StateManager 返回状态数据
4. BatchWriter 调用 PromptBuilder 组装 Director Prompt
5. PromptBuilder 返回完整 Prompt
6. BatchWriter 通过 LiteLLM 调用 Director Agent
7. Director 返回任务卡
8. BatchWriter 调用 PromptBuilder 组装 Writer Prompt（注入任务卡+状态）
9. LiteLLM 调用 Writer Agent
10. Writer 返回初稿
11. BatchWriter 调用 PromptBuilder 组装 Polish Prompt
12. LiteLLM 调用 Polish Agent
13. Polish 返回润色稿
14. BatchWriter 调用 PromptBuilder 组装 Auditor Prompt
15. LiteLLM 调用 Auditor Agent
16. Auditor 返回审计报告
17. BatchWriter 调用 QualityGates.audit()
18. QualityGates 判定 PASS / WARN / BLOCKING
19. 若 PASS：BatchWriter 保存正文 + StateManager.update_after_chapter()
20. 返回 WriteResult 给用户

### 7.2 异常重试时序

若 Auditor 返回 BLOCKING：
1. QualityGates.should_retry() 检查 attempt < max_retries
2. 若可重试：QualityGates.build_retry_prompt() 将失败原因注入下一轮 Prompt
3. BatchWriter 重新调用对应阶段（Writer/Polish）
4. 重试次数 +1
5. 若 3 次仍 BLOCKING：标记为 error，人工介入

## 8. 质量门与熔断机制

### 8.1 BLOCKING 判定矩阵

| 检查项 | 阈值 | 级别 | 触发动作 |
|--------|------|------|---------|
| 字数 < 4050 | 1 次 | BLOCKING | 强制扩写后重跑 Writer |
| 字数 > 4950 | 1 次 | BLOCKING | 硬性截断后重跑 Polish |
| 红线词 > 0 | 1 次 | BLOCKING | 替换后重跑 Polish |
| 禁用词 > 3 | 1 次 | BLOCKING | 消解后重跑 Polish |
| 他字密度 > 15% | 1 次 | WARN | 记录但不阻塞 |
| 句式破坏 < 3/6 | 1 次 | WARN | 记录但不阻塞 |
| 感官细节 < 3 | 1 次 | WARN | 记录但不阻塞 |
| 年代细节 < 2 | 1 次 | WARN | 记录但不阻塞 |
| 爽点 < 2 | 1 次 | WARN | 记录但不阻塞 |
| 视角监狱违规 | 1 次 | WARN | 记录但不阻塞 |
| 章末平结尾 | 1 次 | BLOCKING | 重写节拍 4 |

### 8.2 熔断器（Circuit Breaker）

```python
class CircuitBreaker:
    def __init__(self, failure_threshold=5, recovery_timeout=60):
        self.failure_count = 0
        self.failure_threshold = failure_threshold
        self.recovery_timeout = recovery_timeout
        self.last_failure_time = None
        self.state = "CLOSED"

    def call(self, func, *args, **kwargs):
        if self.state == "OPEN":
            if time.time() - self.last_failure_time > self.recovery_timeout:
                self.state = "HALF_OPEN"
            else:
                raise ServiceUnavailable("LLM API 熔断中")
        try:
            result = func(*args, **kwargs)
            if self.state == "HALF_OPEN":
                self.state = "CLOSED"
                self.failure_count = 0
            return result
        except Exception as e:
            self.failure_count += 1
            self.last_failure_time = time.time()
            if self.failure_count >= self.failure_threshold:
                self.state = "OPEN"
            raise e
```

### 8.3 重试策略

```python
class RetryPolicy:
    def __init__(self, max_retries=3, base_delay=2, max_delay=30):
        self.max_retries = max_retries
        self.base_delay = base_delay
        self.max_delay = max_delay

    def get_delay(self, attempt: int) -> float:
        delay = min(self.base_delay * (2 ** attempt), self.max_delay)
        jitter = random.uniform(0, 1)
        return delay + jitter
```

### 9.1 多项目隔离模型

全局 Orchestrator
    ├── Worker Pool (max_workers=10)
    │   ├── Worker-1 -> Project-A 第 81 章

隔离原则:
- 每个 Worker 拥有独立的 SQLite 连接
- 每个 Worker 拥有独立的 LLM API 上下文
- Worker 崩溃只影响当前章节，Orchestrator 自动重启并重跑

### 9.2 SQLite 并发控制

```python
class WorkerStateManager:
    def __init__(self, db_path: Path):
        self.local = threading.local()
        self.db_path = db_path

    def _get_conn(self):
        if not hasattr(self.local, 'conn'):
            self.local.conn = sqlite3.connect(
                self.db_path,
                check_same_thread=False,
                isolation_level=None
            )
            for pragma, value in SQLITE_PRAGMAS.items():
                self.local.conn.execute(f"PRAGMA {pragma} = {value}")
        return self.local.conn
```

### 13.2 输入校验

| 攻击面 | 防护措施 |
|--------|---------|
| SQL 注入 | 全部使用参数化查询，禁止字符串拼接 SQL |
| 路径遍历 | book.yaml 中的路径经 Path.resolve() 校验，禁止跳出 novel-projects/ |

| SSRF | LLM API 域名白名单，禁止内网 IP |
| Prompt 注入 | Writer Agent Prompt 中禁止包含用户输入（除大纲外） |

### 13.3 敏感数据

- crewai.db 中的 API Key 使用环境变量注入，绝不写入代码或配置文件
- 日志中脱敏：LLM API 响应只记录前 100 字，不记录完整正文
- 项目目录权限：chmod 700 ~/novel-projects/
