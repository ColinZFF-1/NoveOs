## 一、核心理念

### 1.1 为什么是"制片厂"模式？

传统 AI 写作 = 一个 prompt 写一段文字，没有记忆，写到第10章就崩。

本方案 = **4-Agent 协作流水线 + 跨章状态追踪**：

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│ Director │ → │  Writer  │ → │  Polish  │ → │ Auditor  │
│  调度    │   │  写作    │   │  润色    │   │  审计    │
└──────────┘   └──────────┘   └──────────┘   └──────────┘
     ↑                                              │
     └──────── world_state.json 跨章记忆 ───────────┘
```

**Director**：读取 world_state，决定本章埋什么伏笔、收什么债务、谁出场。
**Writer**：拿到 Director 的任务卡 + 人物状态快照，写正文。
**Polish**：去 AI 味，执行句式破坏六式。
**Auditor**：硬指标审计，不过打回重写。

### 1.2 为什么需要跨章约束？

| 问题 | 没有约束 | 有约束 |
|------|---------|--------|
| 人物名字 | 第1章叫顾长卿，第2章变沈砚 | **全程锁定** |
| 配角 | 念安/阿婆完全消失 | **按调度表强制出场** |
| 伏笔 | 埋了不收，收了没埋 | **Director 强制埋/收** |
| 状态 | 纸化程度章间跳跃 | **状态快照传递** |

## 二、系统架构

### 2.1 文件结构

```
【书名】/
├── 【书名】-crewai配置表.md      ← 核心配置（人物/世界观/债务/伏笔）
├── world_state.json               ← 跨章状态追踪器
├── batch_write_v9_direct.py       ← 批量写作脚本
├── launcher.py                    ← Windows 后台启动器
├── state_manager.py               ← 状态管理模块
├── fix_names_v9.py                ← 名字修复脚本（备用）
├── chapters/
│   ├── V8.0/                      ← 旧版正文（参考/标题来源）
│   └── V9.0/                      ← 新版正文（生成后存放）
```

### 2.2 技术栈

| 组件 | 用途 |
|------|------|
| Python 3.12 | 运行环境 |
| crewai-venv | 虚拟环境（crewai + litellm） |
| DeepSeek API | LLM 调用（deepseek-v4-flash） |
| SQLite | 配置存储（crewai.db） |
| JSON | 跨章状态（world_state.json） |

## 三、前置准备

### 3.1 环境安装（一次性）

```bash
# 1. 创建虚拟环境
python -m venv E:/crewai-venv

# 2. 激活
E:/crewai-venv/Scripts/activate

# 3. 安装依赖
pip install crewai litellm
```

### 3.2 API 配置

在系统环境变量中设置：

```bash
OPENAI_API_KEY=sk-你的DeepSeekKey
OPENAI_API_BASE=https://api.deepseek.com/v1
```

或在 `launcher.py` 中硬编码：

```python
env['OPENAI_API_KEY'] = 'sk-你的Key'
```

### 3.3 获取核心脚本

从已有项目（如《纸人婚·替嫁命》）复制以下文件：

```bash
cp batch_write_v9_direct.py 新书目录/
cp launcher.py 新书目录/
cp state_manager.py 新书目录/
cp fix_names_v9.py 新书目录/
```

## 3.1 一键初始化脚本

```python
#!/usr/bin/env python3
"""
新书初始化脚本
用法：python init_new_book.py --name "书名" --path "E:/番茄/小说/书名"
"""

import argparse
import shutil
from pathlib import Path

PAPER_MARRIAGE_DIR = Path(r"E:\番茄\小说\纸人婚·替嫁命")
CREWAI_STUDIO_DIR = Path(r"E:\CrewAI-Studio")


def copy_and_patch(src, dst, replacements):
    with open(src, 'r', encoding='utf-8') as f:
        content = f.read()
    for old, new in replacements.items():
        content = content.replace(old, new)
    with open(dst, 'w', encoding='utf-8') as f:
        f.write(content)


def init_book(book_name, book_path):
    book_dir = Path(book_path)
    chapters_dir = book_dir / "chapters"
    v8_dir = chapters_dir / "V8.0"
    v9_dir = chapters_dir / "V9.0"
    
    print(f"[1/5] 创建目录: {book_dir}")
    v8_dir.mkdir(parents=True, exist_ok=True)
    v9_dir.mkdir(parents=True, exist_ok=True)
    
    print(f"[2/5] 复制核心脚本...")
    files = [
        (PAPER_MARRIAGE_DIR / "batch_write_v9_direct.py", book_dir / "batch_write_v9_direct.py"),
        (PAPER_MARRIAGE_DIR / "launcher.py", book_dir / "launcher.py"),
        (PAPER_MARRIAGE_DIR / "state_manager.py", book_dir / "state_manager.py"),
        (PAPER_MARRIAGE_DIR / "fix_names_v9.py", book_dir / "fix_names_v9.py"),
    ]
    path_replacements = {
        r"E:\番茄\小说\纸人婚·替嫁命": str(book_dir).replace("/", "\\"),
        r"E:/番茄/小说/纸人婚·替嫁命": str(book_dir).replace("\\", "/"),
    }
    for src, dst in files:
        if src.exists():
            copy_and_patch(src, dst, path_replacements)
            print(f"  ✓ {dst.name}")
        else:
            print(f"  ✗ {src.name} 不存在")
    
    print(f"[3/5] 复制模板文件...")
    # 模板文件需要手动填写，这里只创建空文件提示
    (book_dir / f"{book_name}-crewai配置表.md").write_text(
        "# 请从教学版.md中复制配置表模板到这里\n", encoding='utf-8')
    (book_dir / "world_state.json").write_text(
        '{"project": "' + book_name + '"}\n', encoding='utf-8')
    print(f"  ✓ {book_name}-crewai配置表.md (待填写)")
    print(f"  ✓ world_state.json (待填写)")
    
    print(f"[4/5] 复制 crewai.db...")
    db_src = CREWAI_STUDIO_DIR / "crewai.db"
    if db_src.exists():
        shutil.copy2(str(db_src), str(book_dir / "crewai.db"))
        print(f"  ✓ crewai.db")
    
    print(f"[5/5] 完成!\n")
    print(f"新书目录: {book_dir}")
    print(f"\n下一步:")
    print(f"  1. 填写 {book_name}-crewai配置表.md")
    print(f"  2. 填写 world_state.json")
    print(f"  3. 运行 crewai-set-skill 生成配置")
    print(f"  4. 运行 auto_config.py 写入 db")
    print(f"  5. python launcher.py 启动生成")


if __name__ == '__main__':
    parser = argparse.ArgumentParser()
    parser.add_argument('--name', required=True)
    parser.add_argument('--path')
    args = parser.parse_args()
    init_book(args.name, args.path or f"E:/番茄/小说/{args.name}")
```

# 第四部分：常见问题

### Q1: Agent/Task ID 变了怎么办？

`batch_write_v9_direct.py` 中硬编码了 ID：
```python
agent_ids = {
    "director": "A_DSqtHuBjW",
    "writer": "A_Aq3eV72Qw",
    ...
}
```

如果重新生成配置后 ID 变了：
1. 打开 `CrewAI-Studio`
2. 查看 Agents/Tasks 的新 ID
3. 替换脚本中的硬编码 ID

### Q2: 配角出场太多怎么办？

在 `world_state.json` 的 `cast_presence_map` 中收紧 `chapters` 列表：
```json
"chapters": [81, 85, 90, 95, 100]
```

### Q3: 字数偏少/偏多怎么办？

在配置表的**节拍器配置**中调整目标字数，或在 `call_api()` 中增加 `max_tokens`。

### Q4: 人物名字又错了怎么办？

运行修复脚本：
```bash
python fix_names_v9.py
```

或在 `world_state.json` 的 `consistency_rules.name_locks` 中增加更严格的约束。

### Q5: 某章生成失败了怎么办？

```bash
# 单独重跑某一章
python batch_write_v9_direct.py --start 50 --end 50 --model deepseek-v4-flash
```
